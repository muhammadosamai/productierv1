# Rich Text Descriptions (Stories, Issues, Tasks)

## Scope
- Enabled rich text (HTML via Tiptap) for **description** fields in:
  - Story create dialog + story detail panel
  - Issue create dialog + issue detail panel
  - Task create dialog + task detail panel
- Enabled rich text (HTML via Tiptap) for **story acceptance criteria** in:
  - Story create dialog + story detail panel
- Kept list/card surfaces as **plain-text previews** (no rich rendering in lists).

## Storage and Compatibility
- The backend schema and API already accept nullable `text`/`string` descriptions, so no DB migration is needed.
- Descriptions are stored as HTML generated by `RichTextEditor`.
- Existing legacy plain-text descriptions are still rendered safely in detail panels.
- Story `acceptanceCriteria` follows the same storage and compatibility behavior.

## Frontend Changes
- Added shared helper: `src/lib/richText.ts`
  - `renderStoredRichText(...)`: renders legacy plain text as escaped HTML with line breaks and passes through rich HTML.
  - `richTextPreviewText(...)`: strips HTML to plain text for list/card previews.
- Updated create forms to use `RichTextEditor` for description input.
- Updated detail panels to:
  - edit description via `RichTextEditor`
  - display description with `v-html` through `renderStoredRichText(...)`
- Updated list/card previews to use `richTextPreviewText(...)` so HTML is not shown as raw tags.
- Updated story acceptance criteria to:
  - edit via `RichTextEditor` on create/detail
  - display with `v-html` through `renderStoredRichText(...)`
  - use `richTextPreviewText(...)` in story list/table preview
