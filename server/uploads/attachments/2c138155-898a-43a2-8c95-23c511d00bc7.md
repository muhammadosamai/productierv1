# Load Testing Scripts

This directory contains load testing scripts for the Vizt Backend API.

## Prerequisites

### Locust (Python)
```bash
pip install locust
```

### k6 (Go-based)
- Windows: `choco install k6` or download from https://k6.io/docs/get-started/installation/
- macOS: `brew install k6`
- Linux: See https://k6.io/docs/get-started/installation/

## Running Locust Tests

### Web UI Mode (Recommended for exploration)
```bash
cd backend/tests/load
locust -f locustfile.py --host=http://localhost:8000
```
Then open http://localhost:8089 in your browser.

### Headless Mode (For CI/automation)
```bash
# 100 users, spawn rate 10/s, run for 5 minutes
locust -f locustfile.py --host=http://localhost:8000 --headless -u 100 -r 10 -t 5m

# 1000 users stress test
locust -f locustfile.py --host=http://localhost:8000 --headless -u 1000 -r 50 -t 10m

# Output to CSV
locust -f locustfile.py --host=http://localhost:8000 --headless -u 500 -r 25 -t 5m --csv=results
```

### Run Specific Tags
```bash
# Only health checks
locust -f locustfile.py --host=http://localhost:8000 --tags health

# Only swipe operations
locust -f locustfile.py --host=http://localhost:8000 --tags swipe
```

## Running k6 Tests

### Basic Run
```bash
cd backend/tests/load
k6 run k6_script.js
```

### Custom Configuration
```bash
# Override VUs and duration
k6 run --vus 100 --duration 5m k6_script.js

# Different host
k6 run --env BASE_URL=https://api.vizt.app k6_script.js

# Output results to JSON
k6 run --out json=results.json k6_script.js

# Output to InfluxDB (for Grafana dashboards)
k6 run --out influxdb=http://localhost:8086/k6 k6_script.js
```

### Predefined Scenarios
The k6 script includes these scenarios:
- `baseline`: 10 VUs for 1 minute (warm-up)
- `ramp_up`: 0 -> 100 -> 500 -> 1000 VUs over 12 minutes
- `spike`: Sudden 2000 VU spike for stress testing
- `sustained`: Constant 100 req/s for 5 minutes

## Interpreting Results

### Key Metrics
- **RPS (Requests/Second)**: Throughput capacity
- **p95 Latency**: 95th percentile response time
- **Error Rate**: Percentage of failed requests

### Target Thresholds
- p95 latency < 2 seconds
- p99 latency < 5 seconds
- Error rate < 5%

### Common Bottlenecks
1. **High latency at low VUs**: Database query issues
2. **Errors spike at 500+ VUs**: Postgres connection saturation or lock contention
3. **Memory growth**: Background task accumulation
4. **Timeouts**: OpenAI API calls (AI endpoints)

## Recommended Test Plan

1. **Baseline (10 VUs, 1 min)**: Establish healthy response times
2. **Light Load (100 VUs, 5 min)**: Verify system handles normal traffic
3. **Medium Load (500 VUs, 5 min)**: Identify first bottlenecks
4. **Heavy Load (1000 VUs, 10 min)**: Find saturation point
5. **Stress Test (2000+ VUs, 5 min)**: Determine breaking point

## Output Files

Locust generates:
- `results_stats.csv`: Aggregate statistics
- `results_stats_history.csv`: Time-series data
- `results_failures.csv`: Failed requests
- `results_exceptions.csv`: Exceptions

k6 generates:
- `summary.json`: JSON summary of test results
- Console output with detailed metrics
