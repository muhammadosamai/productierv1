# Vizt Backend API

A FastAPI backend for the Vizt travel and place discovery application.

## Features

- **Places API**: List, search, and filter places
- **Categories API**: Browse and filter by categories
- **Swipe API**: Generate random and curated swipe decks
- **Search API**: Full-text search with filters
- **AI Assistant API**: LangGraph-powered travel planning agent with place discovery tools
- **Invites API**: Shareable invite links + contact matching
  - Contact matching stores only hashed identifiers (no raw contacts).

## Tech Stack

- **FastAPI** - Modern Python web framework
- **Motor** - Async MongoDB driver
- **Pydantic** - Data validation
- **Uvicorn** - ASGI server
- **LangChain + LangGraph** - AI agent orchestration

## Getting Started

### Prerequisites

- Python 3.10+
- MongoDB Atlas account (or local MongoDB)

### Installation

```bash
# Navigate to backend directory
cd backend

# Create virtual environment
python -m venv venv

# Activate virtual environment
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### Configuration

Create a `.env` file in the project root:

```env
MONGODB_CONNECTION_STRING=mongodb+srv://...
DATABASE_NAME=google_map_data_v2
COLLECTION_NAME=foursquare_places
OPENAI_API_KEY=sk-...
model=gpt-
5.1VIZT_SHARE_BASE_URL=https://vizt.app
VIZT_APP_SCHEME=vizt
VIZT_IOS_APP_STORE_URL=
VIZT_ANDROID_PLAY_STORE_URL=
INVITE_TTL_HOURS=720

```

### Running the Server

```bash
# Development mode with auto-reload
uvicorn main:app --reload --port 8000

# Or using Python directly
python main.py
```

### API Documentation

Once running, access the interactive API docs:

## API Endpoints

### Places

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/v1/places` | List places with pagination |
| GET | `/api/v1/places/top-rated` | Get top rated places |
| GET | `/api/v1/places/{id}` | Get single place |
| GET | `/api/v1/places/swipe-deck` | Get random places for swiping |

### Categories

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/v1/categories` | List all categories |
| GET | `/api/v1/categories/{id}` | Get category details |
| GET | `/api/v1/categories/{id}/places` | Get places in category |

### Swipe

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/v1/swipe/deck` | Get random swipe deck |
| GET | `/api/v1/swipe/curated` | Get curated deck (mixed) |
| POST | `/api/v1/swipe/deck` | Get deck with exclusions |

### Search

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/v1/search` | Search places |
| POST | `/api/v1/search/filter` | Filter places |
| GET | `/api/v1/search/quick` | Quick search (autocomplete) |

### AI Assistant

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/v1/ai/chat` | Chat with AI travel assistant |

### Invites & Contacts

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/v1/invites` | Create invite link (place or group) |
| GET | `/api/v1/invites/{code}` | Resolve invite details |
| POST | `/api/v1/invites/{code}/accept` | Accept invite |
| POST | `/api/v1/contacts/match` | Match hashed contacts |
| GET | `/i/{code}` | Invite landing page (deep link) |

The AI assistant supports:
- Searching places by description
- Filtering by rating, price, category
- Planning day itineraries
- Recommending hidden gems

## Data Model

The API serves data from a MongoDB collection with 24,000+ Foursquare places including:

- Place name, categories, location
- Ratings and popularity scores
- Photos with Foursquare CDN URLs
- Contact information and hours
- AI-generated summaries

## Development: LangChain Docs via MCP

For development and debugging, you can query the official LangChain documentation using the MCP (Model Context Protocol) server at `https://docs.langchain.com/mcp`.

### Quick MCP Docs Query Script

Create a file `scripts/query_langchain_docs.py`:

```python
"""
Dev-only script to query LangChain docs via MCP.
Useful for looking up API references while developing.

Usage:
    python scripts/query_langchain_docs.py "how to create a tool"
"""

import asyncio
import sys

async def query_docs(query: str):
    try:
        from langchain_mcp_adapters.client import MultiServerMCPClient
        
        client = MultiServerMCPClient({
            "langchain_docs": {
                "transport": "http",
                "url": "https://docs.langchain.com/mcp",
            }
        })
        
        tools = await client.get_tools()
        print(f"Available tools: {[t.name for t in tools]}")
        
        # Find and call the search tool
        for tool in tools:
            if "search" in tool.name.lower():
                result = await tool.ainvoke({"query": query})
                print(f"\nResults for '{query}':\n{result}")
                break
                
    except ImportError:
        print("Install langchain-mcp-adapters: pip install langchain-mcp-adapters")
    except Exception as e:
        print(f"Error: {e}")

if __name__ == "__main__":
    query = sys.argv[1] if len(sys.argv) > 1 else "LangGraph tool calling"
    asyncio.run(query_docs(query))
```

To use, first install the MCP adapter (dev-only):

```bash
pip install langchain-mcp-adapters
python scripts/query_langchain_docs.py "how to use ToolNode in LangGraph"
```

This is for development reference only and is not exposed in the production API.
