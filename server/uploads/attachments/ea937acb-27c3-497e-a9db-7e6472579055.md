# Vizt App

Vizt is a mobile travel and place discovery app built with React Native (Expo) and a FastAPI backend. It combines a large Foursquare-based catalog with personalization, analytics, and an AI assistant to help users decide where to go.

## What it does
- Discover feed with curated modules (for you, right now, trending, top rated, hidden gems, areas, vibes).
- Swipe deck with contextual personalization, filters, and interaction logging.
- Place details with AI summaries, photos, and CTA actions.
- AI assistant for recommendations and day plans.
- Group swipe sessions with shared preferences and matches.
- Shareable invite links for places and group swipes.
- Profile insights (preferences, favorites, history) and analytics.

### AI
- LangChain + LangGraph agent

## Data and storage
- MongoDB stores the places catalog (24k+ Foursquare entries).
- PostgreSQL stores user auth, swipe history, and analytics in `vizt_` tables.
- Feature refresh jobs compute trend stats and recommendation features.
- Contact matching stores only hashed emails/phones (no raw contacts).

### JWT keys (how they work)
- `VIZT_JWT_MASTER_KEY` is the master key used to encrypt the real JWT signing secret.
- The signing secret is **not** set in `.env` and is stored encrypted in the database.
- On first startup, the backend generates a signing secret automatically and stores it
  encrypted with the master key.

### JWT master key setup (production-ready)
- Generate a Fernet key once: `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`
- Store it in your secrets manager as `VIZT_JWT_MASTER_KEY` (same value for all instances).
- For local development, you can place `VIZT_JWT_MASTER_KEY` in `.env` instead.
- Restart the backend after setting the variable.
- Keep `ALLOW_JWT_SECRET_RESET=false` in production. If you ever rotate the master key, set it to `true` for one restart to rotate the encrypted JWT secret, then set it back to `false`. This invalidates existing JWTs.

### Do I need to generate the key?
- **Production**: yes, generate and set `VIZT_JWT_MASTER_KEY` once (shared across all instances).
- **Local dev**: optional. If you do nothing, the server auto-generates a master key and
  stores it in the OS keyring.
